## 🚀 Featured Work

### 🔐 [`AES-Crypto-SoC`](https://github.com/akifmohamed/AES-Crypto-SoC)
**AES-128 hardware crypto accelerator** — `RTL → Yosys synthesis → OpenSTA timing → OpenLane 2 P&R → Virtuoso → GDSII`

### 🧮 [`PipeCore-GDS`](https://github.com/akifmohamed/PipeCore-GDS)
**8-bit, 2-stage pipelined ALU** on SkyWater Sky130 — tapeout-clean physical design
`DRC 0 violations · LVS 100% matched · timing signoff ✅`

### 🧠 APEX NeuralEdge
**6-layer high-speed Edge-AI PCB** — ARM Cortex-M7 (480 MHz), FPGA glue logic, CAN-FD / RS-485 / Ethernet, 5V TPU for on-device inference.

### 📡 Arduino Radar System
Ultrasonic radar (HC-SR04) — real-time angle/distance serialization & visualization.
